# Standard library modules used:
#   ast            — safe AST parsing of app install.py files (v1.2.0+)
#   curses         — interactive TUI (selection menu, scrollbar, colour pairs)
#   datetime       — installation report timestamps (v1.2.0+)
#   importlib.util — dynamic module availability checks (v1.2.0+)
#   json           — GitHub API response parsing
#   os             — root/euid check, path operations
#   platform       — OS detection (Linux / Darwin / Windows)
#   re             — VERSION constant extraction from installed app sources
#   shutil         — directory removal (uninstall), which() for binary detection
#   subprocess     — git clone/pull, systemctl, launchctl, install.py execution
#   sys            — Python executable path, exit
#   tempfile       — temporary files for phased install (v1.2.0+)
#   urllib         — GitHub REST API requests (no third-party HTTP client needed)
#   pathlib        — all filesystem path operations
#   typing         — Optional type hint (Python 3.9 compatibility)
#
# Runtime requirements (system-level, not pip):
#   python3 >= 3.9
#   git            — required at runtime for clone / pull operations
#   sudo / root    — required at runtime; Arsenal enforces geteuid() == 0
#   fuser          — Linux: kill process on a port (package: psmisc)
